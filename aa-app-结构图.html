AA记账 App · 页面结构图

# 手机优先 · 单页应用 · Hash 路由 · Mock 数据

路由结构

  • #login — 登录 / 注册页
  • #home — 项目列表主页
  • #room/{id} — 项目内部（账单、成员）
  • #bill/{id}?room={rid} — 记账表单
  • #settle/{id} — 结算清算页
  • #account — 账号设置
  • #admin — 管理后台（管理员专用）

项目页面 (#room)

  • ① 顶部 — 项目名称 + 成员头像
  • ② 点击头像 → 查看用户信息（Zelle）
  • ③ 账单列表 · 我的支出
  • ④ 他人支出（别人代付的部分）
  • ⑤ 全员结账按钮
  • ⑥ 操作记录 Tab

记账表单 (#bill)

  • 💰 金额 — 数字键盘自动弹出
  • 🏷️ 标签 — 餐饮 / 交通 / 购物 等
  • 👤 支付人 — 默认自己，可 + 添加
  • 👥 分摊给 — 默认全部，可 + 添加
  • 💬 备注 — 可选
  • ✅ 保存并返回 → 回到项目页
